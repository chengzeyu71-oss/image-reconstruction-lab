# 逐像 · 图像重建实验室

从少量色块逐步重建图像，并在不同节点检验视觉模型何时认出内容。重建无需依赖或密钥；AI 识别通过本机服务访问 OpenAI API。

## 运行

只探索像素重建时，直接用现代浏览器打开 `index.html` 即可。要运行 AI 识别实验，在这个目录启动本机服务：

```sh
python3 server.py
```

然后访问 http://127.0.0.1:8000 。要让视觉模型可用，需在启动前通过你自己的终端环境配置 `OPENAI_API_KEY`；服务启动时会显示“AI 评测：可用”。密钥只留在服务进程中，不会发给浏览器或写入项目文件。

程序只监听 `127.0.0.1`。图像重建始终在浏览器中完成；只有点击“运行识别实验”后，所选节点图才经本机服务发送到 OpenAI API。每个节点单独计费，界面会在运行前显示请求数量。原图作为一次基线请求发送。API 使用 [Responses 图像输入](https://developers.openai.com/api/docs/guides/images-vision) 和 [结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)。

## 操作

1. 使用内置的猫、风景、几何示例，或导入／拖入自己的图片。
2. 选择细分策略、元素预算、最小边长和区域 RMSE 停止阈值。
3. 点击播放或按空格；可单步推进、拖动进度、点击阶段缩略图回看。
4. 在重建图、误差图、边缘图之间切换。右侧解释下一个待细分区域的统计量。
5. 点击“比较全部策略”，在同样参数下对比六条质量曲线。
6. 导出 PNG（4 倍尺寸）、SVG 矩形图、当前元素 JSON、完整轨迹 CSV。SVG / JSON / CSV 导出位于曲线旁或下方的区域信息卡片。
7. 在页面下方填写原图主要对象和可接受的同义名称，选“当前策略”或“全部六种策略”，运行 AI 识别。检查结果中的“待判定”项；如“虎斑猫”与“猫”语义相符，手动标为“正确”。导出识别 CSV 留存证据。

## 如何解读 AI 识别实验

- 节点按元素数量约 `1 → 4 → 16 → 64 → 256 → 1024 → 最终` 抽样；重复的最终节点会去重。四叉树的实际元素数可能与目标数略有差异。
- 每个节点使用新的、独立的 API 请求。模型只收到当下重建图和固定的识别任务；它不会收到原图、正确名称、此前回答或“这是一只猫”之类提示。
- 原图基线验证模型是否能识别源图。如果原图也认错，不能把重建失败解释成像素化造成的。
- “首次答对”是**已测试节点**中最早判为正确的一个，不能代表未测试节点的精确阈值。“持续答对”指从该节点到本策略最后一个节点全部答对，且至少有两个这样的节点。错误、无法判断和待判定都不计为正确。模型答案可能在更多元素时反而改变，因此不假设识别能力随元素数单调上升。
- 自动判分只接受与填写标签／同义名称**完全一致**的类别；其他回答留待人工判断。“无法判断”自动记为错误。请保存原始回答和人工判定，并为正式研究在多张图像、多次重复试验后再概括模型能力。单次运行只能作为探索性结果。
- 可比较相同元素数量下不同重建策略的最早识别节点与像素还原度。这样能够区分“像素上更像”与“模型更早认出”是否一致。
- CSV 保存请求模型、API 返回的模型标识、response ID、图像 SHA-256、源图名称、正确标签、回答、人工判定、策略、重建参数和时间。CSV **不包含图像本身**；要完全复现，请同时保存源图和必要的导出 PNG。

## 算法与边界

- 原图等比缩小到最长边 256 像素，不放大小图；透明像素合成到白底。
- 每个叶区域用四舍五入的平均 RGB 表示。指标直接对应这些实际显示和导出的整数色值。
- 四叉树每步用四个子块替换一个父块；只有一个方向还能细分时二分。任何子块不得突破最小边长（原图本身更窄的维度保留）。预算是上限，未必能恰好达到。
- Error = 区域 RGB MSE / 255²；Gradient = 区域平均 Sobel 强度，除以 4×255 并截断到 [0,1]；Entropy = 16 级亮度直方图的 Shannon 熵 / 4。
- 综合优先级 = `(wError * Error + wEdge * Gradient + wEntropy * Entropy) * sqrt(area / imageArea)`。三个权重归一化；全为 0 时等权。
- 误差优先 = `Error * area / imageArea`，即总平方误差排序；边缘、熵优先使用上述面积平方根因子。
- 均匀策略按层级与行列顺序；随机策略给候选区域分配固定种子 42 的伪随机分数。两者仍遵守尺度、阈值和预算约束。
- RMSE 停止阈值为 0 时禁用；非 0 时仅细分局部 RMSE 超过阈值的区域。
- 质量 = `100 * (1 - RMSE / 255)`；PSNR = `20 * log10(255 / RMSE)`；无误差时 PSNR 为无穷。
- 每步增益以百分点（pp）计；单位面积信息价值 IVE 为 `gain / parentArea`。这是一次细分的面积归一化增益，不是单个新增叶元素的增益。
- 重建过程不使用 SSIM、语义识别或显著性模型，不能保证先出现眼睛或其他语义特征。AI 评测在重建完成后独立运行，不影响元素生成顺序。
- 精确的矩形和指标来自积分图；优先队列按区域评分选择候选。改变参数会重新计算整条轨迹并回到起点。

## 文件

- `index.html`：应用界面；`style.css`：响应式样式。
- `engine.js`：独立四叉树、积分统计、优先队列、轨迹与指标，可在 Node 中使用。
- `app.js`：交互、图像导入、画布、示例、比较和导出。
- `test-engine.cjs`：无需额外依赖的算法验证。
- `recognition.js` / `ai-experiment.js`：识别取样、判分、结果界面与导出。
- `server.py`：仅本机可访问的静态文件服务和 OpenAI API 转发；密钥从环境变量读取。

运行测试：`node test-engine.cjs`。

内置示例为程序内绘制的 SVG 插画，不依赖远程图片或字体。
